### Phase 2: Abstracted Data Layer

Build a `MarketDataSource` abstraction that:
1. **NATS stream** (primary, real-time, no rate limits)
2. **REST API** (fallback, polling, rate limited)
3. **Cached data** (last resort, stale but available)

```python
# Target architecture:
class MarketDataSource(ABC):
    @abstractmethod
    async def get_prices(self, items, cities, quality) -> dict: ...
    @abstractmethod
    async def subscribe(self, callback) -> None: ...

class NATSSource(MarketDataSource): ...     # Primary
class RESTAPISource(MarketDataSource): ...   # Fallback  
class CachedSource(MarketDataSource): ...    # Last resort

class MarketDataOrchestrator:
    """Tries NATS first, falls back to REST, then cache."""
    sources: list[MarketDataSource]  # Priority ordered
```

Same pattern for map/zone data:
```python
class ZoneDataSource(ABC):
    @abstractmethod
    def get_zones(self) -> list[Zone]: ...
    @abstractmethod
    def get_connections(self) -> list[Connection]: ...

class Albion2DSource(ZoneDataSource): ...  # Live from albiononline2d.com
class StaticFileSource(ZoneDataSource): ... # From extracted_maps/albion_zones.json
```
